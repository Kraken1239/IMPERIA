# IMPERIA — меховой бутик в Актау

Самостоятельный магазин с редакционной главной страницей, адаптивным каталогом, поиском, фильтрами, избранным, выбором размера, корзиной, записью на примерку и закрытой панелью управления.

## Как работает заказ

Покупатель выбирает модели и оставляет контакты. Сервер сохраняет заявку в Cloudflare D1, выдаёт номер и предлагает открыть подготовленное сообщение в WhatsApp магазина. Сообщение отправляет сам покупатель. Оплата, наличие и способ получения согласуются с менеджером; онлайн-эквайринга нет.

Заявки видны в `/admin`, даже если покупатель не отправил сообщение в WhatsApp. Администратор может изменять статус и удалять заявки с персональными данными. Автоматические уведомления менеджеру не подключены: проверяйте панель или используйте WhatsApp.

## Важно перед наполнением

Три исходных образа — демонстрация с изображениями, созданными ИИ, а не реальные товары магазина. Размеры — пожелания для подбора, цены не придуманы и отображаются по запросу. После сохранения первого товара через `/admin` сайт показывает только каталог администратора. Добавьте реальные фото (HTTPS-ссылки), материалы, цены и размеры; снимите флаг демонстрации только для подтверждённых товаров. Скрытые товары не принимаются в новых заявках.

## Технологии

React 19, TypeScript, Vinext/Vite, Cloudflare Workers, Drizzle, D1. Изображения WebP, локальные шрифты Manrope и Cormorant Garamond. Корзина и избранное — localStorage этого устройства; заявки и каталог — серверная БД.

`selldone/storefront` использован как функциональный ориентир. Его код не копировался, учётная запись Selldone не требуется.

## Локальный запуск

Нужны Node >=22.13, Git и npm.

1. `npm ci`
2. Создайте `.dev.vars` со случайным ключом не короче 24 символов: `IMPERIA_ADMIN_KEY=...`. Никогда не коммитьте этот файл.
3. `npm run build`
4. Примените локальную миграцию: `node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_swift_wind_dancer.sql`
5. `npm run dev` — адрес `http://127.0.0.1:5173`.

## Проверки

- `npx tsc --noEmit`
- `npm run build`
- `node scripts/check-commerce.mjs` — 26 проверок API, только на одноразовой локальной БД. Проверяет также изменение каталога. После проверки удалите локальную тестовую модель командой `node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --command "DELETE FROM products WHERE id = 'qa-local-model';"`.

Проверены в браузере: выбор размера, корзина, форма заявки и подтверждение, поиск, адаптивность.

## Публикация

`.openai/hosting.json` содержит постоянный Sites project ID и привязку D1 `DB`. Публикация через Sites применяет миграции и запускает Worker. В production задайте `IMPERIA_ADMIN_KEY` как secret. Ключ локальной базы и production могут различаться. Новая Sites-версия по умолчанию доступна только владельцу: это версия для просмотра перед открытием покупателям. Публичный доступ и домен настраиваются отдельно по запросу владельца.

Панель использует HttpOnly / SameSite=Strict cookie, в HTTPS — Secure, срок 12 часов. Форма проверяет Origin, согласие, телефон, допустимый размер и количество. Цена берётся из серверного каталога. Для защиты от повторов используется idempotency key, для ограничения заявок — 10 запросов с сохранением в час на технический IP-идентификатор. Это базовая защита; для публичной рекламы с высоким трафиком можно дополнительно подключить Turnstile и уведомления менеджеру.

## Структура

- `app/storefront.tsx` — интерфейс магазина
- `app/globals.css` — оформление и адаптивность
- `app/admin/page.tsx` — панель управления
- `app/api/` — каталог, заявки, авторизация и администрирование
- `lib/catalog.ts` — типы, контакты и демонстрационные образы
- `lib/server.ts` — серверные функции и подпись сессии
- `db/`, `drizzle/` — схема и миграции
- `public/images/` — изображения и WebP-версии
- `public/fonts/` — локальные шрифты

Без секретов и персональных данных в исходниках. Локальные `.dev.vars`, база `.wrangler/` и runtime-файлы исключены из Git.
